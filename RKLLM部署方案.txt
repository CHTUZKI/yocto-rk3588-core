 整镜像用法（推荐）
------------------------------------------------------------

  构建前准备（大文件不在 git）：
    1) deploy/models/Qwen3-4B-Instruct-2507-w8a8-rk3588.rkllm  (~4.6G)
    2) deploy/rkllm/ 下 runtime 二进制
    3) 生成 Agent 依赖包：
         ./scripts/fetch-qwen-agent-aarch64.sh
       → deploy/vendor/qwen-agent-aarch64-site.tar.gz

  构建：
    source poky/oe-init-build-env build
    bitbake rk3588-image-minimal
    # 产物：build/latest/update.img（含模型，体积很大）

  烧录：RKDevTool 刷 update.img，日志须出现 Start to download rootfsA

  烧录后自检：
    ping 192.168.1.14
    ssh root@192.168.1.14
    systemctl status rkllm-server
    # 模型加载可能需数分钟；TimeoutStartSec=600
    curl -sS http://127.0.0.1:8080/v1/models
    ls -lh /opt/models /opt/rkllm /opt/rkllm_server /opt/qwen_agent

  PC 客户端：
    cd rk3588-agent-chat && ./run.sh

------------------------------------------------------------
 踩坑摘要
------------------------------------------------------------

  1. rootfsA:grow → RKDevTool 不写 rootfs（改固定 0x03A00000）
  2. mmc CQE → 大文件写 eMMC 易卡死（设备树删 supports-cqe）
  3. 模型与 runtime 版本对齐：RKLLM 1.2.3 + NPU 0.9.8
  4. 大文件 SCP 中断可导致 EXT4 journal abort → 无法挂载 root → 需重刷
  5. 4B ~4.6G + Agent deps，主机构建需预留充足磁盘；烧录较慢属正常

主机备份：
  build/latest/update.img
  deploy/models/  deploy/rkllm/  deploy/vendor/
